# 📊 Data Professionals Survey — Power BI Dashboard

> Interactive Power BI dashboard analyzing survey responses from data professionals worldwide, covering salary, job satisfaction, work-life balance, and programming language preferences.

---

## 📌 Project Overview

This dashboard visualizes a real-world survey dataset from **data professionals across multiple countries**, exploring:
- Compensation by job title
- Programming language popularity
- Work/life balance and salary satisfaction
- Gender distribution in the data field
- Geographic breakdown of respondents

---

## 📊 Dashboard Visuals

| Visual | Type | Description |
|--------|------|-------------|
| Job Position & Salary Range | Clustered Column Chart | Average salary broken down by role (Analyst, Scientist, Engineer…) |
| Favorite Programming Language | Column Chart | Most popular languages among data professionals |
| Country of Survey Takers | Treemap | Geographic distribution of respondents |
| Work/Life Balance Satisfaction | Gauge | Average satisfaction score (out of 10) |
| Salary Satisfaction | Gauge | Average salary satisfaction score (out of 10) |
| Gender Distribution | Donut Chart | Male vs Female split among respondents |

---

## 🔧 Tools Used

| Tool | Usage |
|------|-------|
| **Power BI Desktop** | Data modeling, DAX measures, dashboard design |
| **Power Query** | Data cleaning and transformation |

---

## 💡 Key Insights

- **Data Scientists** command the highest average salaries, followed by Data Engineers
- **Python** is the dominant programming language across all roles
- **Work/life balance satisfaction** scores higher than salary satisfaction on average
- The survey skews male, reflecting broader industry demographics

---

## 🚀 How to View

1. Download `data-professionals-survey-dashboard.pbix`
2. Open with [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free)
3. Explore the interactive dashboard
